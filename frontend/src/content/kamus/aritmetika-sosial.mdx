Aritmetika sosial adalah cabang matematika terapan yang mempelajari aplikasi konsep hitung bilangan dalam aktivitas perekonomian dan interaksi sosial masyarakat sehari-hari, seperti perdagangan, perbankan, dan perpajakan.

Materi ini merupakan tulang punggung soal cerita pada subtes Penalaran Matematika UTBK SNBT, menguji kejelian literasi finansial peserta.

## Komponen & Atribut Kunci (EAV)

| Topik Finansial | Formula Matematis Dasar |
|---|---|
| **Untung (Laba)** | $\text{Untung} = \text{Harga Jual} - \text{Harga Beli} \quad (\text{Harga Jual} > \text{Harga Beli})$ |
| **Rugi** | $\text{Rugi} = \text{Harga Beli} - \text{Harga Jual} \quad (\text{Harga Beli} > \text{Harga Jual})$ |
| **Persentase Untung** | $%U = \frac{\text{Untung}}{\text{Harga Beli}} \times 100\%$ (selalu dihitung dari harga beli) |
| **Diskon Tunggal** | $\text{Potongan} = \%D \times \text{Harga Awal}$ |
| **Bruto, Tara, Netto** | $\text{Netto (Berat Bersih)} = \text{Bruto (Berat Kotor)} - \text{Tara (Berat Kemasan)}$ |

## Contoh Soal Ujian & Pembahasan Singkat

**Soal Cerita Keuangan:** Seorang pedagang membeli sekarung beras dengan bruto 50 kg dan tara 2% seharga Rp 600.000. Jika beras tersebut dijual eceran seharga Rp 14.000 per kg, berapakah keuntungan bersih pedagang tersebut?

**Pembahasan Kilat:**
1. Hitung tara (berat karung): $\text{Tara} = 2\% \times 50 = 1 \text{ kg}$.
2. Hitung netto (berat beras murni): $\text{Netto} = 50 - 1 = 49 \text{ kg}$.
3. Hitung penerimaan penjualan: $49 \times \text{Rp } 14.000 = \text{Rp } 686.000$.
4. Hitung keuntungan bersih: $\text{Rp } 686.000 - \text{Rp } 600.000 = \text{Rp } 86.000$.

*Kunci Jawaban:* Keuntungan bersih pedagang adalah **Rp 86.000**.
