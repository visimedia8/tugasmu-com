<p class="font-body-md text-body-md text-on-surface-variant mt-0.5">
                  Mobil berhenti total (<code class="font-mono text-sm">v_t = 0</code>), dengan kelajuan awal <code class="font-mono text-sm">v_0 = 20 m/s</code>:
                  <br/>
<code class="px-2 py-1 bg-surface-container-lowest rounded font-mono text-sm inline-block my-1 text-on-surface">v_t² = v_0² + 2 · a · s → 0 = (20)² + 2 · (-5) · s → 10s = 400 → s = 40 meter</code>
